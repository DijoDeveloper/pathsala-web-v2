# Pathsala – Web App for Schools

Pathsala is a school administration dashboard built with React, TypeScript, Vite, and Tailwind CSS.

## Requirements

- Node.js 18.x or later (recommended 20.x or later)
- npm or yarn

## Installation

1. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

2. Start the development server:

   ```bash
   npm run dev
   # or
   yarn dev
   ```

3. Open the app in your browser (default):

   - http://localhost:5173
